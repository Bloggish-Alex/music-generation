# Codec V2 Design

Codec V2 is the sole runtime format: 18 semantic lanes, 48 nominal 0.25-QL slots, full 12-bin chroma, `slot_valid_mask`, and `slot_durations_ql`. A `6/8` bar is 3.0 QL / 12 slots. A partial final slot is valid music time; padding is not rest. Sequence continuity uses stable `source_note_id`, never object identity. Real measure spans, all-part retention policy, tempo/key/CC64 provenance, and quantization residuals are source facts only; pedal is not a tensor target.

The six lane features are ordered as `relative_pitch`, `is_rest`, `is_note_on`, `is_hold`, `normalized_velocity`, and `velocity_ratio`. Relative pitch is `(pitch-base_pitch)/24`; velocity is in `[0,1]`; velocity ratio is a slot-local assigned-lane share in `[0,1]`. Valid rest is exactly `[0,1,0,0,0,0]`; onset sets only `is_note_on`; hold sets only `is_hold`. Invalid padding is `[0,0,0,0,0,0]`, has zero duration, and never participates in a feature or evaluation denominator.

Lane 0 is melody, lanes 1 through 16 are the slot-local harmony set, and lane 17 is bass. Melody chooses highest pitch with velocity-descending/source-ID-ascending ties and preserves a still-active previous melody within seven semitones. Bass chooses the lowest remaining note with the same tie-break. Harmony ordering is pitch, physical track, clipped duration, source onset, velocity, then source ID. `velocity_ratio` divides clamped velocity by the sum for all assigned lanes and is zero for a zero denominator. The 12D bar context sums `max(clipped_duration,0)*clamped_velocity/127` in `(pitch-base_pitch) mod 12` bins and L1-normalizes; empty bars are all zero.
