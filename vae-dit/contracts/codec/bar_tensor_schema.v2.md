# Canonical Bar Tensor Schema V2

`bar_tensor_schema.v2` is the sole runtime format. `voice_tensors.npz` contains `voice_tensors float32[N,18,48,6]`, `slot_valid_mask bool[N,48]`, `slot_durations_ql float32[N,48]`, `bar_contexts float32[N,12]`, `base_pitches int16[N]`, and `base_pitch_valid bool[N]`.

Slots have nominal 0.25 QL duration. A `6/8` bar is 3.0 QL and has 12 slots. Before grid construction, a measured bar end within `1e-6 QL` of a nominal boundary is snapped to that boundary; otherwise its actual duration is retained and the final valid slot is shorter. Each valid duration is positive, durations sum to the snapped-or-retained grid bar length, and invalid padding has false mask, zero duration, zero features, is not rest, and is excluded from all denominators. Capacity is 48; a larger measure is an encoding error.

Lane feature order is `[relative_pitch, is_rest, is_note_on, is_hold, normalized_velocity, velocity_ratio]`. `relative_pitch=(absolute_pitch-base_pitch)/24` and is zero when no valid base exists; `normalized_velocity` is clamped MIDI velocity divided by 127; `velocity_ratio` is the slot-local assigned-lane velocity share. A rest is exactly `[0,1,0,0,0,0]`; onset is `[*,0,1,0,*,*]`; hold is `[*,0,0,1,*,*]`. Exactly one of rest/onset/hold is one for every valid lane-slot.

Lane indices are fixed: `melody=0`, `harmony_00..harmony_15=1..16`, and `bass=17`. Melody is the highest active pitch; equal pitches sort by velocity descending then `source_note_id` ascending. An active prior melody remains melody when its pitch is no more than seven semitones below the current highest pitch. Bass is the lowest remaining note with the same tie-break; it is rest when melody is the only assigned note. Harmony is a slot-local set, never a persistent physical voice: remaining notes sort by pitch, physical track index, clipped duration, source onset, velocity, then `source_note_id`.

For one valid slot, `velocity_ratio = clamp(velocity,0,127) / sum(clamp(assigned_lane_velocity,0,127))`; it is zero when the denominator is zero. `bar_context` has 12 bins: `bin=(pitch-base_pitch) mod 12`, `weight=max(clipped_duration_ql,0)*clamp(velocity,0,127)/127`; sum weights by bin and L1-normalize. Empty or zero-weight bars are all zero. No 11-bin projection is permitted.

When `base_pitch_valid=false`, `base_pitch` has no musical meaning and `bar_context` is exactly twelve zeros. The chroma formula is applied only when `base_pitch_valid=true`.

For source identity, use the dataset-relative normalized POSIX path with `/`, no leading separator, Unicode NFC, and UTF-8 without a BOM. `inner=lowercase_hex_sha256(raw_file_bytes)` (64 ASCII bytes, no prefix); `source_file_identity=lowercase_hex_sha256(utf8(path)+b"\\x00"+ascii(inner))`. `source_note_id=<source_file_identity>:<physical_track_index>:<source_note_ordinal>` uses decimal integers with no padding. An Opus tune appends `__tune_<zero-padded-index>` to song identity before split assignment; its source file identity remains the exact underlying file identity. The manifest stores lowercase `sha256:` hashes of exact archive and index bytes, plus canonical JSON config hash, dataset content-manifest hash, code revision, parser/control provenance, meter distribution, lane capacity, and grid policy.
